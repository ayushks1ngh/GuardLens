# Face detection: Haar cascade vs YuNet (2026-10-14)

**What was measured:** counts, not per-box accuracy (no human-drawn boxes exist yet — see the procedure below).

| Test | Truth | Haar cascade (old default, min_neighbors 5) | Haar (min_neighbors 8) | **YuNet (new default)** |
|---|---|---|---|---|
| 1927 Solvay group photo (`tests/assets/`, public domain), 29 people | 29 faces | 24 found, loose boxes | 24 found | **29 found, tight boxes** |
| `data/samples/mall_cctv.mp4`, 60 frames (a 3×3 mosaic of CCTV feeds; no readable faces) | 0 faces | **116 false faces** (rooftops, parking lots, luggage) | 39 false | **0 false** |
| Speed on the photo (CPU) | | 89 ms | | 64 ms |

Reproduce: `python scripts/setup_face_model.py && python -m pytest tests/test_detectors.py -q`
(the YuNet tests assert ≥ 28/29 faces on the photo and 0 on the CCTV sample).

**Limits of this evidence:** one photo and one video. It proves YuNet is clearly better on those two cases; it does not give
a precision/recall figure for *your* cameras. For that, label your own footage:

## Measuring on your own footage (about 20 minutes)
```bash
python scripts/benchmark_detectors.py frames  mycam.mp4 --every 60 --max 40 --out bench/mine   # 40 evenly spaced frames
python scripts/benchmark_detectors.py draft   bench/mine     # detector guesses -> labels.draft.json + review/ pictures
# open bench/mine/review/*.jpg, then edit labels.draft.json: delete wrong boxes, add missed ones; save as labels.json
python scripts/benchmark_detectors.py run     bench/mine --report docs/benchmarks/mine.md
```
The report gives right / false alarms / missed / precision / recall / F1 per class (IoU ≥ 0.5).
